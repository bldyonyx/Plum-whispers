## ✦ Installation

Plum Whispers is currently available as a locally built Vencord theme.

1. Clone this repository.
2. Install dependencies with `npm install`.
3. Build the theme with `npm run build`.
4. Copy `dist/plum-whispers.theme.css` into your Vencord themes folder.
5. Enable Plum Whispers in Vencord's Themes settings.

## ✦ Behind the whispers

Plum Whispers is organized into modular CSS files, separating colors, typography, textures, backgrounds, messages, interface components, and animations.

The theme uses CSS custom properties to keep its appearance consistent and make visual adjustments easier.

Its decorative textures are layered with adjustable sizes and opacity, creating a softer interface without overwhelming the content.

The project also includes a standalone HTML/CSS illustration used to create the README preview.
